# مولد تقارير تقييم المقررات

تطبيق ويب يقرأ **الخطة الدراسية** و**التقرير التفصيلي** بصيغة PDF، يطابق المقررات بينهما، ويولّد تقرير Word باللغة العربية (RTL).

## الميزات الرئيسية
- قراءة الخطة الدراسية واكتشاف فصولها تلقائياً
- دعم OCR للخطط المصورة (صور ممسوحة)
- معالجة تكرار المقرر في أكثر من صفحة (متوسط كل البنود)
- توليد تقرير Word بالعربية مع جداول نتائج التقييم
- حقل **رمز الفصل الدراسي** يظهر في عنوان التقرير

## طريقة الاستخدام
1. ارفع الخطة الدراسية PDF
2. ارفع التقرير التفصيلي PDF
3. أدخل رمز الفصل (مثال: `461` أو `الفصل الأول 1446`)
4. اضغط **قراءة فصول الخطة** واختر الفصول
5. اضغط **تحليل الملفات** ثم راجع المطابقة
6. اضغط **توليد تقرير Word** وحمّل الملف

## الاعتماديات
- pdfplumber / PyMuPDF
- python-docx
- rapidocr / onnxruntime (OCR للخطط المصورة)
- python-bidi
