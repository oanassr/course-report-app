# مولد تقارير تقييم المقررات

تطبيق محلي بسيط لتحليل خطة دراسية PDF وتقرير تفصيلي PDF، ثم مطابقة المقررات بالرموز والأسماء، وعرض شاشة تأكيد قبل توليد تقرير Word من النموذج الرسمي.

## التشغيل

من مجلد المشروع شغل:

```bat
run_course_report_app.bat
```

ثم افتح:

```text
http://127.0.0.1:8765
```

مسار فحص صحة التطبيق:

```text
http://127.0.0.1:8765/health
```

## سير العمل

1. ارفع ملف الخطة الدراسية PDF.
2. ارفع ملف التقرير التفصيلي PDF.
3. ارفع نموذج Word الرسمي DOCX.
4. اضغط "قراءة فصول الخطة" ليعرض التطبيق الفصول الموجودة في الخطة تلقائياً.
5. اختر الفصول المطلوبة من القائمة المستخرجة من الخطة.
6. راجع شاشة المطابقة:
   - صفحات القياس التفصيلية تدخل في الحساب.
   - صفحات الملخص تظهر للمراجعة ولا تدخل في الحساب مرة ثانية.
   - المقررات المكررة تظهر بحالة "مطابق مع تكرار".
7. أكد المقررات المطلوبة ثم اضغط "توليد تقرير Word".

## طريقة الحساب

لكل مقرر ولكل بند:

```text
متوسط البند = مجموع قيم البند في صفحات القياس التفصيلية / عدد صفحات القياس التفصيلية
```

ثم يحسب متوسط المقرر من متوسطات البنود الإحدى عشرة. النسبة المئوية تحسب من القيمة الخام قبل التقريب:

```text
النسبة = المتوسط الخام * 20
```

## المخرجات

يحفظ التطبيق كل عملية في:

```text
course_report_app/data/jobs/
```

ويولد ملف:

```text
تقرير_تحليل_استبانة_المقررات.docx
```

## النشر على Render

المشروع مجهز للنشر على Render من خلال الملفات الموجودة في جذر المشروع:

```text
render.yaml
requirements.txt
.python-version
```

الخطوات:

1. ارفع المشروع إلى مستودع GitHub.
2. افتح Render واختر New ثم Blueprint.
3. اربط مستودع GitHub الذي يحتوي المشروع.
4. اختر ملف `render.yaml`.
5. بعد اكتمال البناء سيظهر رابط التطبيق.

ملاحظة خصوصية: ملفات PDF وWord التي يرفعها المستخدم تحفظ داخل مساحة تشغيل الخدمة أثناء توليد التقرير. في الاستضافة العامة يفضل إضافة تنظيف تلقائي دوري أو زر حذف للملفات بعد تحميل التقرير.

## فحص الصحة والتنبيه

يوفر التطبيق المسار `/health` ليرجع حالة بسيطة بصيغة JSON. يستخدم Render هذا المسار في `render.yaml` لفحص الخدمة، ويمكن استخدامه أيضاً مع أدوات مراقبة خارجية للتنبيه عند تعطل التطبيق.
